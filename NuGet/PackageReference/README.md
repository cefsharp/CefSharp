# CefSharp - Chromium Embedded Framework .NET binding

CefSharp takes the building blocks provided by the [Chromium Embedded Framework (CEF)](https://github.com/chromiumembedded/cef) and provides a usable .NET implementation. Embed a full Chromium based web browser in your .NET (WinForms, WPF or OffScreen) application.

## Installation

Install via the .NET CLI:

```bash
dotnet add package CefSharp.WinForms.NETCore
```

or via the Visual Studio Package Manager Console:

```powershell
Install-Package CefSharp.WinForms.NETCore
```

Refer to the [Quick Start guide](https://github.com/cefsharp/CefSharp#usage) for the recommended packages and required `MinimumRuntimeVersion`/initialization steps.
